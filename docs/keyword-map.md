## Overlap decisions

- **Duolingo alternatives vs Duolingo vs Sorlio.** Both mention Duolingo. The alternatives page explains *why* and *what kinds* of alternative exist. The comparison page is a direct, conditional head-to-head. They serve different points in the same decision.
- **Best reading apps vs best apps to learn French.** The reading-apps page covers one category in depth. The broader page summarises all categories and links to the reading page for depth.
- **How to learn French vs learn French by reading.** The method guide covers all skills in one plan. The reading page goes deep on one method. Both link to each other.
- **A2 practice vs news.** The A2 page is a fixed passage with exercises. The news page is a method for using news at any level.

## Not targeted (deliberately)

- Brand-name pages for competitors, such as "LingQ review", until pricing and features can be verified.
- Near-duplicate pages such as "best French apps 2026" or "best French apps for beginners" as separate URLs. The existing pages cover those intents within one URL each.
